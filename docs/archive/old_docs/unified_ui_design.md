# v5.2 Agent + Host 统一 UI 设计文档

**目标**：为主机端（Host）和副机端（Agent）建立统一的 UI 设计规范，确保视觉语言一致。

---

## 一、设计原则

### 1.1 统一视觉语言

| 维度 | 规范 |
|------|------|
| 主题 | 深色优先（#1a1a2e 背景），可切换浅色 |
| 字体 | Segoe UI / Microsoft YaHei / Consolas |
| 圆角 | 卡片 8px / 按钮 6px / 输入框 6px |
| 间距 | 8px 基准 / 12px 中 / 16px 大 |
| 信息密度 | 高密度，一屏展示关键数据 |
| 动画 | 仅 Qt Property Animation，无 QTimer 循环 |

### 1.2 双端差异

| 维度 | Agent（副机端） | Host（主机端） |
|------|----------------|----------------|
| 角色 | 被监控电脑后台服务 | 监控电脑前端客户端 |
| GUI | 可选（--gui 模式） | 必需 |
| 导航 | 无（单窗口仪表盘） | 5 页面侧边栏 |
| 数据源 | 本地采集器直供 | WebSocket 订阅 |
| 页面 | 仪表盘（本机数据） | 总览/节点/监控/告警/设置 |

### 1.3 统一组件

Agent 和 Host 共享的组件（位于 `host/gui/widgets/` 或 `common/gui/`）：

| 组件 | Agent 使用 | Host 使用 |
|------|-----------|-----------|
| GaugeCard | 本机仪表盘 | 总览/监控页 |
| StatusBadge | 连接状态显示 | 节点状态显示 |
| MetricBar | 本机指标条 | 节点指标条 |
| QualityBadge | 本机评分 | 节点评分 |
| ChartWidget | 无 | 监控页图表 |
| DetailPanel | 无 | 节点详情面板 |

## 三、Agent 仪表盘布局

Agent 仪表盘（--gui 模式）为单窗口，无导航。

```
+----------------------------------------------------------+
| PC Monitor Agent - 本机仪表盘           127.0.0.1:12345   |
+----------------------------------------------------------+
|                                                           |
|  +--------+ +--------+ +--------+ +--------+ +--------+ |
|  | CPU    | | GPU    | | 内存    | | 网络    | | FPS    | |
|  | [环形] | | [环形] | | [环形] | | [流量] | | [数字] | |
|  | 45%    | | 62%    | | 50%    | | ↑12↓45 | | 142    | |
|  | 65C    | | 71C    | | 16/32GB| | MB/s   | | 7ms    | |
|  +--------+ +--------+ +--------+ +--------+ +--------+ |
|                                                           |
|  +----------------------------------------------------+  |
|  | CPU 使用率 60s 趋势图                               |  |
|  | ▁▃▅▇▆▅▃▁▃▅▇▆▅▃▁▃▅▇▆▅▃▁                            |  |
|  | 阈值: 80% (橙) --- 95% (红)                       |  |
|  +----------------------------------------------------+  |
|                                                           |
|  +---------------------+  +---------------------------+  |
|  | 进程 TOP5           |  | 磁盘 I/O                  |  |
|  | chrome  12%  CPU    |  | C: 读 120MB/s 写 85MB/s |  |
|  | game    8%  CPU     |  | D: 读 30MB/s 写 210MB/s  |  |
|  | game   48%  GPU     |  +---------------------------+  |
|  +---------------------+                                  |
+----------------------------------------------------------+
```

**设计要点**：
- 本机仪表盘为 Agent 独有（Host 无此页面）
- 所有指标本地采集，不经网络
- 进程列表按 CPU+GPU 综合排序
