# Host 前端 UI 设计文档

> **Version**: v5.0
> **Status**: Current（UI 设计参考）
> **Compatibility**: Host PyQt5 GUI 布局设计

**核心思路**：两级页面 —— 总览看全部节点状态，点击进单节点仪表盘。不堆功能，只让数据一眼看清。

---

## 一、页面结构（只有 2 级）

```
总览页（所有节点卡片网格）
    ↓ 点击卡片
节点仪表盘（单节点全部数据）
    ← 左上角返回按钮回到总览
```

就这么简单。没有侧栏，没有 7 个页面，没有复杂导航。

### 卡片设计

每个节点卡片分两行：
- **头部**：状态圆点 + 节点名 + IP + RTT
- **指标条**：6 个关键指标并排，每个指标 = 标签 + 数值 + 迷你条形/圆环

```
+--------------------------------------------------+
| ● 游戏主机    192.168.1.100    RTT 0.45ms        |  ← 头部
+--------------------------------------------------+
| CPU    GPU    内存     网络      FPS    评分       |  ← 指标标签
| 45%    62%   14/32GB  ↑12↓45   142    98         |  ← 数值
| ████   ████   ████     ██     [大字]  [圆]        |  ← 可视化
+--------------------------------------------------+
```

### 指标可视化方式

| 指标 | 可视化 | 颜色逻辑 |
|------|--------|----------|
| CPU | 水平条形 40px | <80% 绿, 80~95% 橙, >95% 红 |
| GPU | 水平条形 40px | 同上 |
| 内存 | 水平条形 40px | <80% 绿, 80~90% 橙, >90% 红 |
| 网络 | 双行：↑上传 ↓下载，小条形 | 静态色(蓝) |
| FPS | 大号数字（有帧率时）/ 灰色 —（无帧率时） | >60 绿, 30~60 橙, <30 红 |
| 评分 | 径向小圆环 36px | >=80 绿, 60~79 橙, <60 红 |

### 顶部筛选栏

三个筛选按钮：[全部] [异常] [在线]
- 全部：显示所有节点
- 异常：只显示评分 < 80 或离线的节点
- 在线：只显示已连接的节点

节点数显示：「已连接 3/4」

### 离线节点处理

离线节点卡片灰化，显示：
- 上次在线时间
- 上次收到的数据快照（最后有效帧的 CPU/内存/网络）

## 四、仪表盘详细设计

### 第一层：6 个仪表盘卡片

横排 6 个等宽卡片，每个卡片高度约 140px。

```
+-------------+
|    CPU      |  ← 标签，12px 灰色
|             |
|   [环形图]   |  ← 中央大号环形，直径 80px
|    45%      |  ← 环形内数字，24px 粗体
|             |
|   65°C ●   |  ← 底部辅助指标，14px，颜色随阈值
+-------------+
```

**CPU 卡片**：
- 环形：cpu.total_usage，颜色绿/橙/红
- 底部：cpu.package_temp_c（温度颜色阈值：80/85°C）

**GPU 卡片**：
- 环形：gpu.usage_percent，颜色绿/橙/红
- 底部：gpu.core_temp_c（温度颜色阈值：80/85°C）

**内存卡片**：
- 环形：ram.usage_percent，颜色绿/橙/红
- 底部：「14.2 / 32 GB」（used / total）

**网络卡片**：
- 不用环形，用两行箭头：
  - ↑ 12.3 MB/s（上传，橙色箭头）
  - ↓ 45.6 MB/s（下载，蓝色箭头）
- 底部：网卡名 + 链路速度

**FPS 卡片**：
- 不用环形，用大号数字居中
- fps 数值，48px 粗体
- 底部：帧时间 7.04ms + 1%Low 118
- 无帧率时显示灰色「N/A」

**评分卡片**：
- 径向圆环（270° 弧），中心显示分数 + 等级
- 底部：RTT 0.45ms + 丢包 0.0%

### 第二层：两张宽折线图

左右各一张，高度 200px。

**左图：CPU + GPU 使用率叠加折线**
- 两条线叠加：蓝=CPU，橙=GPU
- Y 轴 0~100%
- 两条阈值虚线：橙 80%，红 95%
- X 轴：最近 60 秒

**右图：网络流量面积图**
- 两个半透明面积叠加：蓝=下载，橙=上传
- Y 轴自动范围（MB/s）
- X 轴：最近 60 秒

### 第三层：磁盘 + 进程

左右各一块。

**左：磁盘 I/O**
- 读写折线图（多盘符用不同颜色区分）
- 每个盘符一行文字：盘符 + 读速 + 写速 + 用量条

**右：进程 TOP5**
- 表格形式，按 CPU+GPU 综合排序
- 每行：进程名 + CPU% + GPU% + 内存
- 前 3 名高亮

## 七、交互规范

### 导航
- 总览页 → 点击卡片 → 节点仪表盘
- 节点仪表盘 → 点击「← 返回」→ 回到总览页
- 浏览器式前进/后退（如果用 Web 技术）或 QStackedWidget 切换

### 刷新
- 1 秒刷新（QTimer 驱动）
- 折线图维护 60 点滑动窗口（deque）
- 新数据从右进，旧数据从左出
- 卡片数值实时更新，环形图平滑过渡（300ms 动画）

### 无数据处理
- 帧率字段为空/N/A → FPS 卡显示灰色「—」
- 温度为空 → 显示「N/A」灰色
- 整个节点离线 → 总览卡片灰化，仪表盘显示「节点离线」覆盖层

### 响应式
- 总览卡片网格：自适应列数（最小 320px/卡）
- 仪表盘卡片：6 卡横排 → 窄屏折为 3+3 或 2+2+2
- 折线图：最小宽度 400px

## 八、技术选型

**PyQt5 + pyqtgraph**（推荐）

| 组件 | 实现方式 |
|------|----------|
| 环形图 | QPaintEvent + QPainter.drawArc |
| 径向仪表 | QPaintEvent + 弧形 + 指针 |
| 折线图 | pyqtgraph.PlotWidget（实时滚动） |
| 柱状图 | QPaintEvent + QPainter.drawRect |
| 面积图 | pyqtgraph.PlotWidget + fillBelow |
| 页面切换 | QStackedWidget（2 页） |
| 卡片网格 | QGridLayout + 自适应列数 |

零新依赖。pyqtgraph 已在常见 PyQt5 生态中，pip install 即可。
