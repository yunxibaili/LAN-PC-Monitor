# v5.2.x Frozen

> **冻结起始**: v5.2.3（CI 全绿，Release Ready）
> **原则**: 稳定分支只修缺陷，不引功能。

## Status

**v5.2.x frozen** —— 本分支/版本线不再接受新功能。

## Allowed

- ✅ Crash fixes（崩溃修复）
- ✅ Security fixes（安全修复）
- ✅ Release blocking bugs（阻塞发布/部署的缺陷）

## Not Allowed

- ❌ New features（新功能）
- ❌ Architecture changes（架构变更）
- ❌ Schema changes（数据库结构变更）

## 变更流程

1. 判断是否属于 Allowed 三类；不确定时默认拒绝。
2. Allowed 修复仍需：本地全量回归 + CI 全绿。
3. 非 Allowed 变更一律排入 v5.3（见 `docs/core/ROADMAP.md` / `docs/issues/v5.2.3_known_issues.md`）。

## Tag 策略（统一规则，长期有效）

| 类型 | 格式 | 示例 |
|------|------|------|
| 正式版本 | `v5.x.y` | `v5.2.3` |
| Release Candidate | `v5.x.y-rcN` | `v5.2.3-rc1` |
| 发布验证点（不可变） | `v5.x.y-release` | `v5.2.3-release` |
| 长期基线 | `v5.x-final` / `v5.x-lts` | `v5.2-final` |
| 开发验证 | `main` | — |

规则：

- **v5.2.3-release is the immutable publication tag for v5.2.3 after CI validation.**（不可变，不随后续 commit 移动）
- 禁止 `v5.2.4` / `v5.2.4-release` / `v5.2.4-final` / `v5.2.4-hotfix` 这类随意 tag；修复统一以 `v5.2.3-rcN` 验证、正式版重新编号。
- 历史 tag（`v5.2.3` 等）一经发布不再移动。
