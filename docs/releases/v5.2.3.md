## Architecture

```
Collector
 → Persistence (MetricPersistenceService)
 → Storage (StorageService / SQLite)
 → Query API (HistoryFacade)
 → History UI (HistoryVM → HistoryPage)
```

- 分层：GUI → Page → ViewModel → Facade → Service → Storage/Repository → SQLite
- 6 页面全部 COMPLETE：Dashboard / Nodes / Monitor / Alerts / History / Settings
- Signal 驱动，无 QTimer 轮询；VM 不依赖 PyQt5；sqlite3 仅在 host/storage/
